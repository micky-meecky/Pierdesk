# Contributing to Pierdesk

Thank you for using Pierdesk. 感谢你使用 Pierdesk。

## Issues are welcome

Please open an issue for bugs, compatibility problems and ideas. A useful report says:

- your Pierdesk version (Settings → About) and Windows version;
- what you expected and what happened instead;
- the steps to reproduce it, and whether both computers run the same Pierdesk version;
- for connection problems: whether both computers are on the same private network.

Please do not paste the contents of Pierdesk's log files or screenshots that show device names, addresses or
fingerprints unless you are comfortable making them public; remove or mask anything personal first.

If you found a security problem, do not publish the details in an issue. Report it privately; see [SECURITY.md](./SECURITY.md).

## Pull requests

Pierdesk is maintained by one person. For now it does **not** accept feature pull requests, so you do not spend time on
work that cannot be merged. Small fixes to documentation or typos are fine to send. This policy may change later.
